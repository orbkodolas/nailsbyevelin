# Nails by Evelin

- `frontend/` – React + Vite + GSAP weboldal (foglalás, árlista, utalvány)
- `backend/` – foglalási és fizetési API (lásd `backend/README.md`)
- `shared/catalog.json` – árak és házirend, a frontend és a backend közös forrása
- `tools/` – `convert-images.sh` (képek → webp), `shot.mjs` (headless képernyőkép lépésekkel)

Fejlesztés: `cd backend && npm start`, `cd frontend && npm run dev`.
